关键业务规则（来自流程图）
发货主体发货单由服务方新增提交，实际发货由委托方按发货单详情进行
接单范围东南组 / 西部组 / 北部组 / 系统外组 / 华南公司店铺
押金流押金付款 → 到账确认 → 押金结算 → 押金退还付款 → 确认退还 → 到账确认
对账时点需租期结束后才可发起对账
委托结算依据已出租的商品数量及租期结束后做委托结算
取消委托直至服务商下架商品、不再接单，即可取消委托
开票口径根据已出租商品、按委托费用开票；租期结束商品按委托价格开票
单据体系服务方一套（租金对账单 / 押金退还单），委托方一套（销售对账单 / 开票）
