# 租售店铺 · 租赁订单管理（前端原型）

依据流程图《商品租赁业务流程》做的**可视化业务页面**，不是流程图的截图或复刻：

- **`index.html` 租赁订单管理**（主页面）：把流程图里的 26 个环节变成订单的**状态机**，
  列表按状态筛选、按环节显示待办，详情页把订单在流程中的位置**可视化**，并可直接在当前环节办理、流转。
- **`flow.html` 业务流程**（参考页）：同一套后台里的流程图查看页，供对照业务规则用。

技术栈：纯 HTML + CSS + 原生 JS，无构建、无依赖。**双击 `index.html` 即可运行**。

## 三、订单管理页（index.html）

**列表页**（与参考截图同构）

- 状态筛选大按钮：全部 / 待接单 / 已接单 / 押金结算 / 待发货 / 待签收 / 租期中 / 待退租 / 待对账 /
  待付款 / 待归还 / 押金退还 / 待开票 / 已完成，每个按钮带实时条数
- 查询条件：订单编号、承租单位、店铺名称、订单类型、下单人、创建时间区间
- 表格：序号 / 订单类型 / 订单状态 / 订单编号 / 店铺 / 承租单位 / 订单总额(元) / 已对账金额(元) /
  **当前待办（哪个角色办什么）** / 操作；含分页

**详情页**（可视化 + 可办理）

1. **流程进度条**：11 个阶段步骤条（下单 → 议价 → 接单 → 押金结算 → 发货签收 → 租期 → 退租对账 →
   租金结算 → 归还定损 → 押金退还 → 开票结束）+ 完成百分比
2. **流程轨迹**：按流程图顺序列出 26 个环节，已完成（✓ 带时间与办理人）、当前待办（高亮 + 办理按钮）、
   未开始（灰）、已跳过（划线）、被驳回后重走的历史环节
3. **按环节办事**：按钮即流程图里的流转，点击后订单推进到下一环节；带金额输入（押金、议价总额、损坏扣款）
4. **金额与单据**：订单总额 / 押金 / 已缴押金 / 已对账金额 / 已付租金 / 损坏扣款 / 已退押金，随流转自动联动
5. **流转日志**：谁、什么时候、在哪个环节做了什么（含跳过节点的记录）

试试：在列表点任意订单编号 → 详情页点当前环节的按钮，进度条、轨迹、金额、日志、列表状态会一起变；
在「议价待确认」点**驳回议价**可以看到流程回到「是否议价」。

## 五、接后端时改哪里

`orders.js` 里三块数据即"接口契约"，替换即可，渲染层不用动：

| 常量 | 作用 |
| --- | --- |
| `STEPS` | 流程环节（id / 名称 / 办理方 / 说明 / 状态标签 / 是否新增 / 是否可选） |
| `ACTIONS` | 每个环节的待办动作与流转目标（`next`），即流程图连线的代码化 |
| `RAW` | 订单列表数据（编号、类型、店铺、承租单位、金额、创建时间、当前所处环节） |

真实接口建议：列表 `GET /rent/orders?status=&no=&tenant=&page=`，
详情 `GET /rent/orders/{no}`（返回当前环节 + 已完成环节时间线 + 金额），
办理 `POST /rent/orders/{no}/action`（body: 环节 id + 动作 + 金额），
前端只需把 `doAction()` 里的本地推进换成接口回调后重新拉取详情。

## 六、放进 Axure RP

Axure **没有导入 HTML 的功能**（网页无法解析成可编辑元件），所以用「内联框架」把页面**嵌进去**。
为了免去资源目录的麻烦，本目录额外提供了**单文件版**：

```
orders-standalone.html      CSS/JS 全部内联，单个文件即可运行（Axure 嵌入推荐用这个）
```

### 嵌入步骤

1. 把 `orders-standalone.html` 复制到原型输出目录，例如 `<输出目录>\files\orders.html`
   （文件名可改，建议保持英文）
2. Axure 里拖一个 **Inline Frame（内联框架）** 元件，尺寸建议 **≥1200×760**
   （页面 `min-width:1180px`，比这窄会出现横向滚动条）
3. 双击框架 → **Link Properties** → **Link to an external url or file** → 填
   `files/orders.html`（相对路径，换电脑不失效）；也可以直接选本地文件，会写成 `file:///…` 绝对路径
4. Style 面板勾 **Hide Borders**；Scroll 按需
5. **必须用「发布 → 生成 HTML 文件」打开输出目录里的页面查看**
   —— Axure 的**预览模式与 Axure Cloud 都无法加载本地文件**（官方限制：预览走本地服务器，
   浏览器不允许它读取磁盘上的 `file://` 文件）

### 要在 Axure Cloud 上分享

本地文件不会被打包上传。把 `orders-standalone.html` 托管到内网/静态服务器，iframe 里改填
`http://内网地址/orders.html` 即可；服务器**不要**设置 `X-Frame-Options: DENY` 或
CSP `frame-ancestors`，否则会被拒绝嵌入。

### 注意事项

- 父子页面之间**不能互相传变量**（浏览器跨域安全限制，Axure 官方文档亦说明）
- 页面无外链字体/图片，不会因资源加载失败变形；字体用系统字体，Axure 里重画时选「微软雅黑」对齐
- 单文件版未打包「业务流程」页，相关入口点击会提示；
  如果要连流程图页一起嵌，用目录版的 `flow.html`（或让 flow 页也出一个单文件版）
- 页面内的下拉/输入/按钮在 iframe 内都可正常交互（纯前端，无后端依赖）
