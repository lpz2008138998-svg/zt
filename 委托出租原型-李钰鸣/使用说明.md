# 委托出租原型 · 使用说明

## 怎么打开（三种，任选）

### 1. 最简单：双击 HTML（推荐）

直接双击 **`index.html`**（总览页），或 `b01.html` ~ `b15.html`、`s01.html` ~ `s11.html`、`a01.html` ~ `a11.html` 任意一个。

**样式是完整的**——本原型的 `app.css` 全部使用颜色字面值、不含 CSS 自定义属性，
所以 `file://` 直接打开也能正常加载样式（已实测：页面底色 `#F2F2F2`、表格边框、按钮颜色均正确）。

### 2. 在 IDEA 里打开

* 项目树里右键 `index.html` → **Open in Browser** → 选 Edge / Chrome
* 或右键 → **Open In → Explorer**，再双击
* 或者直接打开根目录的 **`委托出租原型.html`**（专门做的入口页，里面有全部 37 个页面的链接）

### 3. 起本地服务（可选）

双击 `start-prototype.bat`，会自动起服务并打开浏览器：

```
  Prototype server is running
  URL : http://127.0.0.1:8932/index.html
```

**关闭那个黑色窗口**就停止服务。只有当浏览器策略拦截本地文件、
或你需要把原型分享给别人局域网访问时，才需要这种方式。

## 端口被占用时

默认用 8932。如果提示端口被占用，可以在命令行里换一个：

```
start-prototype.bat 8933
```

（在文件夹地址栏输入 `cmd` 回车，然后敲上面这行。）

## 与上级原型的关系

本文件夹是**独立新增**的，上级 `租售店铺询价原型10.5.原` 里原有的 16 个文件**一个字都没有改动**。

新增到上级目录的只有一个文件：`委托出租原型.html`（入口页）。

删掉 `委托出租原型` 文件夹和 `委托出租原型.html` 即可完全还原，不影响原有原型。

（说明：上级 `租售店铺.html` 外壳里虽然有「出租系统」标签和 `委托商品管理 / 委托商品查询`
菜单项，但其系统切换交互在导出件里未生效——实测点击「出租系统」后左侧菜单不变。
页面内容区也是靠空 `<iframe>` 在运行时装填，URL 不在 HTML 中。
因此委托出租无法"只加内容不改前端"挂进那个菜单，故采用独立入口。）

## 门户页新增的「委托出租」页签

在 `租售店铺（lxj0530）.html`（门户页）里，原有 `销售业务 / 采购业务 / 出租业务` 三个页签的

## 怎么改内容

页面是脚本生成的，**不建议手改 HTML**（下次生成会被覆盖）。改这几个：

| 想改什么 | 改哪个文件 | 改完执行 |
|---|---|---|
| 页面文字、字段、表格数据 | `_build\gen.py` | `python _build\gen.py` |
| 左侧导航、页面清单 | `_build\nav.json` | 同上 |
| 需求/交互说明文档 | `_build\genspec.py` | `python _build\genspec.py` |
| 颜色、字号、按钮、表格样式 | `_build\app.css` | 然后跑 `python _build\gen.py` |

生成脚本需要 Python。没装的话也可以直接手改 HTML 应急，
但别删掉页面顶部的 `<link rel="stylesheet" href="app.css">`。

## 内容依据

- 业务依据：《委托出租业务流程》流程图（委托方 / 服务方 / 承租方三方泳道）
- 关键规则：发货单由服务方开、实际发货由委托方执行；需租期结束后才可发起对账；
  依据已出租数量及租期做委托结算；服务商下架不再接单即可取消委托；
  委托方按委托价格开票、服务方就委托费用开票。
- 单据体系：服务方一套（租金对账单 / 押金退还单），委托方一套（销售对账单 / 开票）。
