# 盘古循环资源平台 · 店铺模块原型

盘古循环资源平台「店铺模块」的交互原型，基于 **Axure RP** 生成，用于业务评审与需求确认。

线上演示：<https://consignment-sale-demo.app.workbuddy.host/>

---

## 一、怎么打开

### 方式 1：直接看线上版（推荐）
访问上面的演示链接即可，电脑浏览器打开效果最好。

> 原型按 **1920px** 宽设计，手机竖屏打开会缩得很小，建议**横屏**或使用电脑/平板。

### 方式 2：本地运行

因为本原型依赖同级资源目录（`resources/`、`data/`、`files/`、`images/`、`plugins/`），
**不能只打开单个 HTML 文件**，否则会白屏。

**正确做法**：用本地 HTTP 服务打开（避免浏览器对 `file://` 的限制）

```bash
# 任选其一，在项目根目录执行
python -m http.server 8000
npx serve .
```

然后浏览器访问 <http://localhost:8000/>，会自动进入门户页。

> 如果只是想快速看看，直接双击 `index.html` 也可以（会自动跳转到 `门户.html`），
> 但个别浏览器的本地文件安全策略可能导致部分资源加载异常，建议优先用上面的 HTTP 方式。

## 三、目录结构

```
.
├── index.html                    # 入口（跳转到门户）
├── 门户.html                     # 主门户页
├── 委托出租功能_Demo.html         # 委托出租
├── 委托出售功能_Demo.html         # 委托出售
├── 租售店铺（lxj0530）.html       # 租售店铺主页面
├── ...                           # 其他业务页面
│
├── data/                         # Axure 页面数据（document.js / styles.css）
├── files/                        # 各页面的样式与数据（按页面名分目录）
├── images/                       # 各页面图片资源
├── plugins/                      # Axure 插件资源（站点地图、批注等）
└── resources/                    # Axure 运行时（jQuery、axure 脚本、基础样式）
```

> **注意**：以上目录是 Axure 生成的强依赖，**不要单独删除或移动其中任何一个**，
> 否则对应页面的样式或交互会失效。

## 四、技术说明

- **原型工具**：Axure RP
- **运行时**：jQuery 3.7.1 + Axure Runtime
- **纯静态**：无后端、无数据库，全部为前端资源
- **导航实现**：在 Axure 原生动态面板基础上，用原生 JS 做了自适应布局与下拉菜单增强，
  相关脚本位于 `门户.html` 底部（搜索 `DEMO 新增`）

---

## 五、已知限制

1. **手机适配**：原型按 1920px 设计，未做移动端响应式适配，建议在电脑上查看。
2. **数据为模拟数据**：所有列表、金额、状态均为演示用静态数据，未接后端接口。
3. **部分页面为占位**：标注「Demo · 待开发」的页面仅展示入口与流程骨架。
